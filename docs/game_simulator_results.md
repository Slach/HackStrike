# Симулятор баланса — результаты прогонов (2026-11-20)

Батч-симулятор матчей 4×4 на **боевом коде сервера**: `server/game_simulator_bench_test.go`
(запрос владельца «прогнать 1000 игр и посмотреть баланс»). Боты играют через настоящий
протокол (`handleMessage`: input/fire/run/ctrl/enter/respawn/jackout), сервер авторитарно
симулирует 30 Гц с инъекцией часов — 1000 матчей ≈ 85 с реального времени на 10 воркерах.

## Как запускать

```bash
cd server && go test -run TestSimulatorBench -count=1 \
  -sim.games=1000 -sim.workers=10 -sim.tag=mixed -sim.out=/tmp/gamesim
```

Флаги: `-sim.games` (0 = skip в обычном `go test ./...`), `-sim.workers`, `-sim.seed`,
`-sim.tag`, `-sim.out` (JSONL по играм + сводка в `/tmp/gamesim`), `-sim.teams "план0,план1"`,
`-sim.comps "comp0,comp1"` (фиксация для абляций), `-sim.passive 1|2` (команда-жертва),
`-sim.fixvault` (абляция геометрии d5/d6, см. дыру №1). Отладка одного матча: `TestSimDebug`.

Составы (у каждой команды 1 хакер + 3 «мяса»): `3AR`, `2AR+SN`, `3HV`, `2HV+SN`, `2SN+AR`,
`SN+2HV`, `AR+HV+SN`, `rnd`. Стратегии хакера: `door_rush` (код d3–d6 через SRV1),
`safe_rush` (safe_key → crack), `hybrid`, `defense` (watcher/firewall/antivirus/chaff),
`disrupt` (газ/двери/камеры), `valve_siege` (код + клапан v3). Планы мяса: escort/push/hold/hunt,
изредка «brute» — физический перебор кода на клавиатуре.

## Методика и допущения

- **Честность**: своё состояние (`progs/scanned/items`) и публичный мир (двери, клапан,
  physafe — всё видно всем через snap.props) боты читают напрямую; враги — только через
  перцепцию (LOS + 30 м + FOV 140°) и интеллект-каналы протокола (cam-лента, report-пеленг,
  radar, alert, extract-броадкасты). Симметрично для обеих команд.
- **Навигация**: высотная сетка 0.5 м строится из коллайдеров карты по правилам физики
  (autostep 0.55), A* с динамическими дверями; лава/газ — штрафы пути. Сетка моделирует
  **серверную** коллизию 1:1 — то, что через неё проходит, пройдёт и в игре.
- **Скилл** ботов одинаково распределён по командам (прицел с гауссовой ошибкой, реакция,
  дальность боя по классу); ff-контроль: не стрелять сквозь своего.
- Балансовые числа не менялись; карта — без изменений (кроме абляции `-sim.fixvault`).

## Прогоны

| прогон | игр | что проверялось |
|---|---|---|
| mixed1000 | 1000 | рандомные составы×стратегии, обе стороны активны |
| fixvault | 1000 | то же + закрыт обход хранилища (дыра №1) |
| passive1 / passive2 | 300+300 | одна команда «жертва» (только база), другая — свободное выполнение целей |

Сырые данные: `/tmp/gamesim/games_*.jsonl` (по-игровая статистика) и `summary_*.json`.

## TL;DR — главные выводы

1. **Дыра (геометрия): хранилище обходится без кода** — створки d5/d6 лежат поперёк проёма
   стены, по бокам остаются проходы ~1.85 м. Боты ходят через них постоянно.
2. **Дыра (баланс): восточная команда сильнее** — 64.6% решённых матчей (35.4% у запада,
   16.3% ничьих). Причина — асимметрия сети: t2 (у базы востока) воткнут в магистраль,
   t1 (у базы запада) — в тупиковый островок.
3. **Extract доминирует**: 66% матчей кончаются выносом сейфа, медиана победы — **73 с**.
   Дверной код добывается за 33–49 с, хранилище открывается к ~47 с.
4. Газовые ловушки ботами не сработали ни разу за 1000 игр (0 взведений) — механика есть,
   но против ботов с обходом объёмов она мертва; у людей может играть иначе.
5. Брутфорс клавиатур под огнём почти не работает: дверь 13.7% попыток, сейф 0% —
   анти-флуд 2 с держит.
6. Здоровые механики: щит SRV (гринд 2–3 зарядов на код), firewall (1752 упора сканов за
   1000 игр), радар/камеры (шлют сотни срезов/кадров за матч), респавн-цикл, ff ~4%.

## Дыра №1 — обход хранилища мимо d5/d6 (геометрия)

Стены хранилища (2 этаж, x 21.5–22.5 и 41.5–42.5) имеют проёмы z 30–34 под двери d5/d6,
но боксы дверей лежат **поперёк** проёма: `d5 pos=[22,8,32] size=[4,3,0.3]` → x 20–24,
z 31.85–32.15. Сверху и снизу створки остаются щели **z 30–31.85 и 32.15–34 (~1.85 м)** —
игрок (0.6 м) проходит насквозь. d3/d4 закрыты корректно (щели по 0.35 м < 0.6 м тела).

- В mixed1000: vaultOpen в 672 играх при door-коде в 730; в ablation с закрытым проёмом
  доля ничьих выросла 16.3%→20.8%, доля extract-побед по коду — без «бесплатных» входов.
- **Фикс — одна строка данных карты**: у d5/d6 `size=[0.3,3,4]` (створка вдоль проёма).
  Менять карту только с подтверждения владельца (§ «Карта — данные»).

## Дыра №2 — асимметрия сторон (терминал t2 vs t1)

Граф сети несимметричен при симметричной геометрии:

- **t2 (восток, 61,1,32) — кабель в s5** → вся магистраль (s2/s3/srv1/netsafe/v3…).
- **t1 (запад, 3,1,32) — кабель в s4**, а s4 соединён только с d1 и cam1: тупиковый
  островок. Западный хакер из своей базы попадает только в дверь d1 и камеру cam1;
  за кодом/клапаном ему надо идти ногами к радио r1/r2 (мид, под огнём) или делать
  «дорогой вход» в s1.

Цифры (mixed1000, обе стороны активны):

| метрика | команда 0 (запад) | команда 1 (восток) |
|---|---|---|
| дверной код добыт | 254/1000 игр за 48.9 с | **476/1000 игр за 33.3 с** |
| код сейфа добыт | 24/1000 за 146.8 с | **112/1000 за 92.5 с** |
| extract-победы | 204 | **455** |
| итог по решённым матчам | 35.4% | **64.6%** |

Абляция fixvault поднимает запад с 35.4% до 39.5% — то есть обход хранилища объясняет
~4 п.п. преимущества востока, остальное — сетевая асимметрия. **Кандидат-фикс**:
кабель t1→s1 (bw 20, «симметризует» t2↔s5) или перенос s4 на магистраль. Решение — за
владельцем (менять граф только через ГДД).

## Пассивные бенчмарки (выполнение целей без пуша мяса)

- «Восток добывает код» в 53% ничем не contested игр (запад — 29%). NB: «пассивная»
  команда всё равно играет хакером-дефенсом (firewall/antivirus/watchers) — это
  чистая сеть против сети, и восток всё равно вдвое чаще доходит до кода.
- Конверсия «код → extract» почти 100%: если код добыт, победа — вопрос десятков секунд.
  Значит, весь бой идёт **до** добычи кода: интерсепт хакера/носителя и есть игра.

## Стратегии хакера (win-rate, обе стороны смешаны)

| план | игр | win% |
|---|---|---|
| door_rush | 574 | **59.0%** |
| valve_siege | 243 | 56.6% |
| hybrid | 229 | 53.2% |
| safe_rush | 317 | 40.7% |
| defense | 327 | 39.7% |
| disrupt | 310 | 38.3% |

Выводы: дверная линия — сильнейшая (быстрее и надёжнее safe-линии: 33–49 с против
92–147 с). safe_rush проигрывает в гонке (дека-декрипт 60 с / перенос на SRV + двойной
гринд щита). defense/disrupt как самостоятельный план слабы — но их ценность проявляется
в паре: против door_rush чистая defense затягивает матч (см. byPlan в summary), а
winrate-разрыв door_rush vs defense ≈ +19 п.п. — дефенс-хакер в одиночку не спасает.

## Контр-механики: что сработало, что нет (за 1000 игр)

| механика | наблюдение | вердикт |
|---|---|---|
| щит SRV ×3 + реген 30 с | 3326 сжиганий (3.3/игру); код всё равно добывается | работает как «таймер-гринд», не как стоп |
| backoff сейфа ×2^ступень | макс. ступень 0 — попытки почти всегда с первой | не видно в данных: либо ок, либо не достигается |
| firewall | 1752 упора сканов; переносит в стагмейты | работает против разведки |
| watcher+radar | 315k radar-срезов, 4k alert'ов | intel-канал живой, дефенс реагирует |
| камеры (vision) | 1.2M кадров-меток | активный источник позиций |
| antivirus | **0 блокировок** за 1000 игр | в ботском исполнении не достигается (умирает раньше установки) — требует плейтеста |
| газовые ловушки | **0 взведений / 0 киллов** | боты обходят объёмы (навсетка), триггер «враг внутри» не наступает; у людей может быть иначе — проверить вручную |
| брутфорс клавиатур | дверь 22/154 игр (13.7%), сейф 0/154; ~80 тыс. проб | 2-сек анти-флуд держит; перебор — тактика безнадёжная под огнём |

## Здоровье матча

- Исходы: extract 65.9%, time 29.3% (из них 77% — полные стагмейты без единого кода),
  frags 4.8%. Ничьи 16.3%.
- Длительность: extract-матчи медиана **73 с**, frag-матчи ~400 с, тайм-ауты 600 с.
- Бой: 13.5 киллов/матч, точность ~69% (ботовский прицел — прок-уровень), ff 3.9% киллов,
  лава 621 килла (в основном рывки через хранилище до открытия клапана).
- Хакер: ~80% времени матча в деке, 50.5% его смертей — **прямо в джек-ине** (§5.4
  «тело беззащитно» работает: хакер — главная цель).

## Ограничения методики (читать перед выводами)

1. Боты — прок-уровень прицела и карта-знание (обход газа/лавы по сетке): газ недооценён,
   «человеческие» ошибки не моделируются.
2. Стагмейты (17%) — артефакт пассивных планов обеих сторон; у людей таких паттернов меньше.
3. Бот-дефенс не координируется с мясом (нет «командных» ролей по intel) — ценность
   defense-плана занижена.
4. Все выводы — про h2dm1 и текущие числа ГДД §3/§16; любое изменение карты/баланса
   требует перепрогона.

## Рекомендации (в порядке приоритета)

1. **Закрыть обход d5/d6** (одна строка данных карты, после подтверждения владельца).
2. **Симметризовать сеть терминалов**: кабель t1→s1 (или перенос s4) — иначе запад
   структурно слабее на ~15 п.п. winrate.
3. Плейтест: проверить руками газ (0 у ботов) и antivirus — две механики, не показавшие
   себя в бенче.
4. Понаблюдать за extract-гонкой в человеческом плейтесте: ботовая медиана 73 с означает,
   что дефенс должен ловить носителя почти сразу после открытия хранилища.
5. Стагмейты: если и у людей будут «обе команды сидят в деке» — подумать про мягкий
   стимул к активности (уже есть +10 за канал — работает).
