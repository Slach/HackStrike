# Симулятор баланса — результаты прогонов (2026-11-20, ревизии 2026-11-21)

Батч-симулятор матчей 4×4 на **боевом коде сервера**: `server/game_simulator_bench_test.go`
(запрос владельца «прогнать 1000 игр и посмотреть баланс»). Боты играют через настоящий
протокол (`handleMessage`: input/fire/run/ctrl/enter/respawn/jackout), сервер авторитарно
симулирует 30 Гц с инъекцией часов — 1000 матчей ≈ 85 с реального времени на 8 воркерах.

> Ревизия 2026-11-21: по решениям владельца закрыт обход d5/d6, сеть симметризована
> (c45 + зеркальные клавиатуры d4), газ отравлен (яд), брутфорс переписан на
> двухфазный алгоритм владельца + эстафета. Прогнано ~3400 игр в 9 батчах.

## Как запускать

```bash
cd server && go test -run TestSimulatorBench -count=1 \
  -sim.games=1000 -sim.workers=8 -sim.tag=mixed21 -sim.out=/tmp/gamesim
```

Флаги: `-sim.games` (0 = skip в обычном `go test ./...`), `-sim.workers`, `-sim.seed`,
`-sim.tag`, `-sim.out` (JSONL по играм + сводка в `/tmp/gamesim`), `-sim.teams "план0,план1"`,
`-sim.squads "план0,план1"` (планы мяса), `-sim.comps "comp0,comp1"` (фиксация для абляций),
`-sim.passive 1|2` (команда-жертва), `-sim.fixvault` (абляция геометрии d5/d6),
`-sim.basework=12` (абляция длительности base-канала physafe). Отладка одного матча:
`TestSimDebug`.

Составы (обычно 1 хакер + 3 «мяса»): `3AR`, `2AR+SN`, `3HV`, `2HV+SN`, `2SN+AR`,
`SN+2HV`, `AR+HV+SN`, `3SN`, `rnd` и **безхакерные** `noh4` (4 мяса), `noh4SN3HV`
(1 снайпер + 3 хеви). Стратегии хакера: `door_rush`, `safe_rush`, `hybrid`, `defense`,
`disrupt`, `valve_siege`, **`valve_brute`** (клапан → физический перебор кода).
Планы мяса: escort/push/hold/hunt/brute и новые **`cover_brute`** (кооп-перебор кода
двери эстафетой + прикрытие; при открытом клапане — то же для кода сейфа),
**`wave`** (мясная волна: каждый сам перебирает, вскрыл — несёт), **`assassin`**
(охота на вражеского хакера, победа по фрагам).

## Методика и допущения

- **Честность**: своё состояние (`progs/scanned/items`) и публичный мир (двери, клапан,
  physafe — всё видно всем через snap.props) боты читают напрямую; враги — только через
  перцепцию (LOS + 30 м + FOV 140°) и интеллект-каналы протокола (cam/radar/report/alert/
  extract, метки с ID игрока). Симметрично для обеих команд.
- **Навигация**: высотная сетка 0.5 м из коллайдеров карты по правилам физики
  (autostep 0.55), A* с динамическими дверями; лава/газ — штрафы пути. Сетка моделирует
  **серверную** коллизию 1:1.
- **Скилл** ботов одинаково распределён по командам; ff-контроль: не стрелять сквозь своего.
- Балансовые числа не менялись; карта — без изменений (кроме абляций).
- **Урок отладки**: половину «дыры №2» прошлого отчёта (64.6% vs 35.4%) создавал не
  баланс, а баг ботов — западный хакер шёл джекаться к радио в мид вместо своего
  терминала. Починен; вывод: симметрия самой симуляции проверяется так же строго,
  как симметрия карты.

## TL;DR — главные выводы (после фиксов 2026-11-21)

1. **Стороны симметричны**: дверной код 35.5 с (запад) vs 35.8 с (восток) — было
   48.9 vs 33.3; решённые матчи 45.5% vs 54.5% (было 35.4/64.6). Остаточные ~9 п.п. —
   в пределах шум+offset physafe ([33,33] на 1 м восточнее центра, мелочь).
2. **Умный брутфорс владельца работает и силён**: перепись цифр (0000…9999) →
   перестановки мультимножества ≈ 17-25 проб (~40-60 с соло, анти-флуд 2 с);
   эстафета N ботов легитимна (анти-флуд персональный) → дверь с прикрытием
   вскрывается в **80-95% игр за ~15-25 с после подхода**. Кооп-брутфорс — теперь
   полноценная стратегия, не fallback.
3. **Extract доминирует ещё сильнее: 74% матчей** (медиана 94 с), хранилище открыто
   в 79% игр. Base-канал 6→12 с срезает extract лишь на ~6 п.п. (абляция) —
   гонка решается ДО и В хранилище, не на базе. Предложения — отдельный раздел.
4. **Безхакерная команда может выигрывать** через брутфорс двери + танк лавы
   (heavy платит ~134 HP за рейс через хранилище и выживает): 26-30% побед
   против команды с хакером. Сценарий «1 снайпер + 3 хеви ломятся и выносят по
   очереди» — работает, но проигрывает 70/30.
5. **Assassin-мета (3 снайпера охотятся на хакера)**: 48% против зеркального себя;
   75% матчей кончаются фраг-лимитом, хакер добывает код лишь в ~33% игр — охота
   сильно давит хакерскую игру, но сама по себе не доминирует.
6. Газ (0 взведений) и antivirus (0 блоков) в ботском исполнении мертвы — проверять
   руками на плейтесте; ядовитый DoT (10 с × 2.5 HP/s после выхода) ботами не
   достигается по той же причине.

## Брутфорс: ответы на вопросы владельца

**«Почему не сработал брутфорс сейфа? Может, не коллективная игра ботов?»** — Да, так и
было: старый алгоритм бота перебирал позиции по одной (до 40+ проб = 80+ с под
анти-флудом), брут-бот ходил один и умирал под огнём; сейфовую клавиатуру он пытал
стоя **в лаве** (без клапана) — смерть за ~8 с. Что сделано:

1. **Двухфазный алгоритм (предложение владельца)**: перепись 0000…9999 даёт, какие
   цифры в коде (hintMatch считает точные позиции; сумма переписи = 4, обрыв раньше
   десятой пробы) → перебор всех перестановок мультимножества (код FNV — цифры
   МОГУТ повторяться, максимум 24 кандидата). ~17-25 проб вместо ~40.
2. **Эстафета**: анти-флуд 2 с — **персональный** (`player.enterAt`), поэтому рота
   ботов у клавиатуры пробует по ротации с каденцией 2с/N. Легитимно (кооп-механика).
3. **Прикрытие**: план `cover_brute` — рота стоит у клавиатуры, боем обслуживается
   общий combat-слой; после вскрытия — пуш/вынос; при открытом клапане — фаза 2,
   эстафетный перебор кода СЕЙФА у physafe (лавы нет).

Цифры:

| сценарий | дверь брутом | сейф брутом | итог |
|---|---|---|---|
| обе команды cover_brute (cbrute/cbrute2) | 236-255 из 300 (**~80%**) | 3 из 300 | extract в 99% игр |
| valve_brute соло (escort, без эстафеты) | 141/300 (47%) | 0 | t0 32.7% против door_rush |
| fullchain (клапан+эстафета двери+сейфа) | **380/400 (95%)** | 22/400 | **t0 57.8%** против door_rush |

Вывод: физический перебор с прикрытием и эстафетой — **конкурентен сетевому пути**
(дверь ~15-25 с после подхода против ~35 с декрипта) и fullchain-цепочка уже
**обыгрывает** door_rush. Если перебор должен остаться fallback'ом для безхакерных
команд, кандидаты-ограничители (решение владельца): анти-флуд на КЛАВИАТУРУ
(разделяемое окно 2 с на всех), подсказка только N/4 без «переписи» (например
скрывать совпадения при >1 неверной позиции — нет), или рост цены ошибки
(backoff ×2 на ступень — есть для сейфа, нет для дверей).

## Extract-доминирование: цифры и предложения

- mixed21: **74% матчей — extract-победа** (медиана 94 с), хранилище открыто в 79%
  игр, сейф брался 3299 раз, носители погибли 2570 раз (78%!) — но волны подборщиков
  всё равно доносят. Фраг-матчи 5.6%, тайм-ауты 20% (154/204 без единого кода).
- Абляция `basework12` (base-канал 6→12 с): extract 68% против 74% — эффект есть,
  но слабый: бой решается до зоны сдачи, а канал на базе почти не прерывается
  (там безопасно).
- Предложения (решение владельца, числа только через ГДД):
  1. **Бить носителя выгоднее**: +фраг/команда-очко за убийство носителя (стимул
     интерсепта всей командой, а не «2 ближайших бота»).
  2. **Канал на базе прерывается уроном** — уже так; усилить окно: base 12 с
     (абляция выше) или зона сдачи дальше от спавна (носитель открыт дольше).
  3. **Лава жёстче**: heavy танкит рейс через хранилище за ~134 HP (25 HP/s × 2×2.7 с
     ходьбы). При lavaDPS 30-35 рейс становится смертельным без клапана — безхакерные
     команды теряют путь «танком», но клапан-шлюз для хакерских команд остаётся.
  4. **Интерсепт до хранилища** — уже работает: весь бой идёт до открытия; дефенсу
     важнее ловить хакера/брутеров на подходе, чем охранять базу.

## Assassin-раш (запрос: «3 снайпера + хакер убивают чужого хакера, победа по фрагам»)

Реализован план мяса `assassin` (цель — вражеский хакер через LOS/радар-метки с ID)
и состав `3SN`. Assassin vs assassin (300 игр): **48%/52%** — зеркально-сбалансирован;
75% матчей до фраг-лимита (медиана ~280 с); хакеры умирают по 18 раз за матч
(26% всех киллов), дверной код добывается лишь в ~33% игр (против ~68% в mixed).
Вывод: охотничья мета душит хакерскую игру, но сама не доминирует — полезный
контр-стиль, а не чит. ff-убийства у снайперов выше (охота сквозь своих).

## Безхакерные команды (запрос: «у одной хакер есть, у других только мясные»)

| матчап | победа команды с хакером | путь безхакерных |
|---|---|---|
| rnd+хакер vs noh4 (4 мяса, wave) | **62.7%** | брут двери 33% → танк лавы → вынос |
| rnd+хакер vs noh4SN3HV (1SN+3HV, wave) | **69.7%** | то же, тяжелы танкуют лучше |

Волна «выносим по очереди» работает буквально: сейф берётся 433-464 раза за 300 игр,
носители умирают в лаве сотнями раз, но 26-30% матчей безхакерные доносят. Дыры нет —
хакер остаётся структурным преимуществом, но «мясо само» не беспомощно (важно для
баланса соло-игры).

## Стратегии хакера (win-rate, mixed21, обе стороны смешаны)

По парам план×план устойчивые тренды (n≈30-105 на пару): door_rush остаётся сильнейшим
(51-68% против большинства), defense/disrupt как самостоятельные планы слабы
(30-44%), но затягивают матч вдвое (400-450 с против 130-160 с). safe_rush в чистом
виде проигрывает door_rush (27-65% зеркально — т.е. симметрично слабее).

## Ограничения методики (читать перед выводами)

1. Боты — прок-уровень прицела и карта-знание (обход объёмов по сетке): газ/яд
   недооценены, «человеческие» ошибки не моделируются.
2. Бот-дефенс не координируется с мясом по intel (нет командных ролей) — ценность
   defense-плана занижена.
3. Эстафетный брутфорс ботов идеален по координации (ротация без потерь): люди
   медленнее — цифры успеха 80-95% это верхняя граница.
4. Все выводы — про h2dm1 и текущие числа ГДД §3/§14/§16; любое изменение
   карты/баланса требует перепрогона.

## Ревизия 2026-11-21 (II): лестничный газ + носитель-цель №1 + base 12 с

Решения владельца после обсуждения отчёта: **(1)** 4 газовых клапана g3–g6 на
всех лестницах, объёмы на оба этажа (y 0..9), зеркальные пары g3↔g4, g5↔g6,
проводка на s4/s5; disrupt-план ботов теперь захватывает ВСЕ газы и рулит ими
(«захватить все G, отключая по мере необходимости»). **(2)** убийство носителя
PHYSAFE = **+5 команде** сверх фрага (раньше бонуса не было — был только +10 за
первый старт канала; FF по своему носителю не награждает, ловушки-владельцы —
тоже +5). **(3)** base-канал 6→12 с; **(4)** лаву не трогаем — контр-игра
убийством носителя.

| extract-победы | 74.0% | **67.6%** | −6.4 п.п. |
| медиана extract-матча | 94 с | **136 с** | +42 с на защиту |
| фраг-финишы | 5.6% | **12.6%** | бонус носителя сделал фраг-путь живым |
| средний счёт | 12.6 | **19.2** | +5 за носителя работает |
| подбора сейфа | 3299 | **7226** | волны подборщиков учащаются |
| длительность | 220 с | 260 с | матч длиннее |
