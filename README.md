# HackStrike

Браузерная сессионная командная FPS-игра (WebGL) с двумя видами геймплея:
обычный FPS-вид и вид «хакера» с кибердекой, влияющий на окружение
(вдохновение — Dystopia mod). Клиент + авторитарный сервер, WebSocket, тик 30 Гц.

## Стек (решено 2026-11-14, см. docs/research/)

| Слой | Выбор |
|---|---|
| Клиент | TypeScript + Vite + Babylon.js 9.x |
| Сервер | Go 1.27 + `coder/websocket`, JSON-фреймы |
| Транспорт | WSS через тот же origin, что и клиент (nginx проксирует `/ws`) |
| Публикация | docker-compose + публичный zrok-шеринг, дальше itch.io |

## Текущее состояние

Играбельный командный режим 4v4 на карте h2dm1 (два этажа, точечная
симметрия). Три пути победы: 50 фрагов команды, 10 минут, извлечение
PHYSAFE (унести на базу или «хайст» — вскрыть кодами из сети).

- `server/` — authoritative-симуляция 30 Гц, одна комната-горутина:
  движение/автоогонь с лаг-компенсацией (rewind), HP/урон/респаун, killfeed;
  кибер-слой — устройства и сеть с честными ресурсами (CPU/NPU/MEM/NET),
  программы хакера (portscan/vulnscan/trojan/…) и контр-меры
  (watcher/firewall/antivirus); газовые клапаны/лава; режим данных — сейф,
  код-замок, носитель. Диагностика: `/api/diag`, `/api/diagdump`; `/healthz`.
- `client/` — Babylon.js-воксельная карта, meatview FPS + кибердека хакера
  (тайловый WM, zsh-палитра, живые ленты камер; UI — DOM-оверлеи),
  миникарта с пеленгом выстрелов, мобильная адаптация (тач-управление,
  PWA-установка).
- `scripts/e2e_smoke.mjs` — e2e-проверка полного конвейера;
  `server/game_simulator_bench_test.go` + `docs/game_simulator_results.md` —
  симулятор баланса (1000 матчей на боевом коде сервера).

## Запуск

```bash
# всё, включая публичный zrok-шеринг (нужен ZROK2_ENABLE_TOKEN в .env):
docker compose up -d --build

# адрес шеринга:
docker compose logs zrok-share | grep -A2 zrok

# локально без zrok (клиент на http://127.0.0.1:9999):
docker compose up -d --build game-client game-server
```

Разработка без docker:

```bash
# терминал 1 — сервер (слушает :8080):
cd server && go run .

# терминал 2 — клиент (vite на :5173, /ws проксируется на :8080):
cd client && npm install && npm run dev
```

## Что смотреть в HUD

- **link** — ONLINE/OFFLINE с авто-reconnect (backoff до 8 c)
- **snaps/s** — должно быть ~30; через zrok это главный индикатор живости туннеля
- **rtt** — RTT до сервера (ping каждые 5 c)

## Дорожная карта

Сводка; полная версия с деталями — ГДД §10 (docs/game-design.md):

1. ✅ **M0 — скелет**: WS 30 Гц, healthchecks, Babylon-заглушка, zrok-шеринг
2. ✅ **M1 — FPS-ядро**: воксельная арена, 4 класса, движение+autostep,
   автоогонь+magnetism+rewind, счёт/killfeed/HUD/миникарта, команды и
   авто-ребаланс — плейтест пройден
3. ✅ **M2 — кибер-базис**: терминалы/switch/кабели, джек-ин/джек-аут,
   дека (тайловый WM), portscan/vulnscan/trojan, двери как контроллеры —
   плейтест пройден
4. ✅ **M3 — дуэль хакеров**: watcher/firewall/antivirus, камеры (живая
   картинка), кибер-миникарта — плейтест пройден
5. ✅ **M4 — ловушки**: газовые клапаны (включая лестничный газ на все 4
   лестницы), отравляющий яд, лава→огонь+водяные клапаны
6. ✅ **M5 — данные**: MEM/cp/decrypt, SRV-стойки со щитом ×3,
   NETSAFE/PHYSAFE (извлечение = мгновенная победа), код-замок d3 (код из
   сети или перебор с подсказками), сеть с bw/backplane/циклами — баланс
   выверен симулятором (1000 игр)
7. ✅ **M6 — осведомлённость**: пеленг выстрелов, cam-лента союзникам +
   вражеские метки на миникарте, патруль/поворот/зум камер, REC-индикация
   (полная FOV-модель миникарты — по плейтесту, ГДД §17.2)
8. ⬜ **M7+**: боты-добивка слотов, пресеты деки, апгрейды,
   оружие-переключение, лифты/мосты/турели/генератор, редактор карт,
   compiler (NPU-синтез), itch.io-релиз

Ближайшая очередь — открытые пункты плейтест-фидбека (онбординг «что делать
новичку», отклик стрельбы в мир) и бэклог идей ГДД §10.1 (антидот, сценарные
режимы с силовой поддержкой, shutdown/wipe деки хакера).
